# Richbox

Animated status indicator for React with 10 states.

[Demo](https://mishanaer.com/ui/richbox) · [Component](src/richbox.tsx)

Run with [Bun](https://bun.sh):

```sh
bun install
bun run dev
```

Colors: [Deslop](https://github.com/mishanaer/deslop). Demo controls: [Fluid Functionalism](https://www.fluidfunctionalism.com) ([license](demo/react/LICENSE.upstream)). [MIT](LICENSE).
